# Conta Segura — Frontend

Interface web da API de contas bancárias, construída com React, TypeScript e Vite.

## Executar localmente

Com a API disponível em `http://localhost:8080`:

```bash
npm install
npm run dev
```

O Vite encaminha as requisições de `/api` para o backend durante o desenvolvimento.

## Verificações

```bash
npm run typecheck
npm run lint
npm run build
```
